## 项目简介
SafeTensors Toolkit 是一个基于 MoonBit 的原生 CLI 与库，用于在模型加载前对 SafeTensors 容器做结构合法性审计、比较两个容器之间的结构差异，并执行确定性的 whole-tensor 分片与合并操作。它完整实现 SafeTensors v1 容器形态：8 字节小端 header 长度、严格 UTF-8 JSON header、`__metadata__`、tensor dtype/shape/ranges 以及连续 data buffer。整个流程只做结构校验与不透明 byte-range 复制，不执行模型、不解释 tensor 数值，从而在不可信输入上保持有界的内存与 I/O 行为。

## 核心功能范围
- 严格 header 校验：有界 prefix 读取、严格 UTF-8 JSON 解析（拒绝重复键、非法转义、超深嵌套）、layout 完整性检查（区间覆盖、重叠、空洞）
- 信息查询：header-only 统计、dtype 分布、按选择器查询 tensor 声明
- 结构 Diff：两个有效快照的确定性结构差异，不读取 tensor 数据
- 分片/合并：确定性的 whole-tensor 贪心分片计划与标准 Hugging Face 风格 index，合并时校验 index/shard 覆盖
- tensor 重命名：header-only 事务性重命名，保留全部 payload range
- native CLI：validate / info / diff / split / merge 命令与标准化退出码

## 原创或参考说明
本项目为 SafeTensors 格式的独立 MoonBit 原生实现，未移植或复制任何上游源代码。格式语义、dtype 位宽矩阵与 Hugging Face shard-index 约定参考 huggingface/safetensors 官方文档（Apache-2.0），仅作为格式规范来源；测试 fixture 均由项目自行生成的确定性 ASCII 字节构造，未内置任何真实模型权重。运行时依赖 moonbitlang/async 与 moonbitlang/x。项目采用 Apache-2.0 许可证。
